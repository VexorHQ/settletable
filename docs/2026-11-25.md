## Yang patah (dan cara memperbaikinya)

1. **Skrip `.ts` di `hardhat run` tidak bisa import file `.ts` lain.**
   Hardhat 2.22 memuat skrip `.ts` sebagai ESM native (type-stripping
   Node): import extensionless gagal, import `.js` gagal (file tidak ada).
   Perbaikan: skrip Hardhat ditulis `.cjs` (CommonJS) — `require()` lewat
   hook ts-node dan bisa me-resolve `src/lib/mandate.ts`.
2. **ts-node mode CJS menolak `moduleResolution: bundler`.**
   Error TS5095 saat `.cjs` me-require file `.ts`. Perbaikan: kunci
   `"ts-node": {"compilerOptions": {"module": "commonjs",
   "moduleResolution": "node"}}` di `tsconfig.json` — hanya dipakai
   ts-node, tidak memengaruhi `tsc` atau Next build.
3. **Kunci test Hardhat yang saya ketik manual salah.** Akun #0 hasil
   ketikan memberi alamat yang salah; kunci #2 cacat (panjang ganjil).
   Perbaikan: akun diturunkan dari mnemonic test Hardhat yang sudah
   publik (`test ... junk`, `addressIndex` 0/1/2) — ketiganya terverifikasi
   cocok dengan alamat Hardhat 0xf39F…/0x7099…/0x3C44….
4. **Alamat kontrak dari receipt lowercase, viem checksummed.**
   Assert `stored.token === mockAddress` gagal karena casing.
   Perbaikan: bandingkan lewat `getAddress()`.
